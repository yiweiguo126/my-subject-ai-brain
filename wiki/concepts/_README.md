# wiki/concepts/ — 概念页

一概念一页，费曼风格，由 AI 从 `raw/` 课件编译生成，学生审校。

- 文件名：`{English-Name}.md`（如 `Example-Concept.md`）
- frontmatter：`tags`、`courses`、`confidence`、`last_reviewed`、`created_at`
- `confidence` 与 `last_reviewed` **只由学生复习时的回答更新**
- 末尾 `Open Questions` 由学生自己填，AI 不得代填

> 模板层零学科：本目录不含任何预设学科内容，长什么完全取决于你导入的课件与 `config.md`。
