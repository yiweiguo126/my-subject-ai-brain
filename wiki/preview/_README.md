# wiki/preview/ — 预习笔记

> 由「**预习**」技能写入，属于**数据层**：升级模板时永不覆盖。
> 这里存的不是 AI 的讲义，而是**学生本人在引导中确认的理解、自己的总结、课后自己想通的结论**，以及材料覆盖不到而保留的疑问。

## 规则

| 项 | 约定 |
|---|---|
| 文件名 | `{course_name}-预习-{NN}.md`，NN 从 01 递增 |
| 写入者 | AI 只在**学生确认后**局部写入；原话照录，不润色 |
| 章节 | 材料盘点 / 认知起点 / 引导轨迹 / 我确认的理解 / 我自己的总结 / 我后来想通的 / 保留疑问 / 沉淀去向 / 下一步（缺项写「本轮无」，不删章节） |
| 保留疑问 | 只停在这里，**不得**写成概念页或结论；待学生补材料或形成结论后再入库 |
| 掌握度 | 预习**不改** `confidence` / `last_reviewed`；它们只由「复习」时学生的回答更新 |
| 引用 | 每条事实性内容标注 `依据：[[来源页]] §章节` |

## 与相邻目录的分工

| 目录 | 谁在写 | 写什么 |
|---|---|---|
| `wiki/sources/` | 「导入」 | 原始材料的关键要点（可回溯依据） |
| `wiki/concepts/` | 「导入」+「预习」追加「我的理解」 | 概念页与学生本人确认的理解 |
| `wiki/preview/` | 「预习」 | 引导轨迹、学生的原话、保留疑问 |
| `wiki/exam-prep/` | 「出题」/「复习」 | 练习题与费曼复习卡 |

> 预习页与概念页通过 `[[双向链接]]` 互连；AI 不代填 `Open Questions`，不生成标准答案页。
