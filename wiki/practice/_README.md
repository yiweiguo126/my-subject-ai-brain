# wiki/practice/ — 实践记录

> 由「**实践**」技能写入，属于**数据层**：升级模板时永不覆盖。
> 这里存的是**学生本人**在操作流程、动手做项目、调试排错时的**真实步骤、观察到的现象与问题**，以及自己确认的结果；不是 AI 的讲义，也不是 AI 代做的操作结论。

## 规则

| 项 | 约定 |
|---|---|
| 文件名 | `{course_name}-实践-{NN}.md`，NN 从 01 递增 |
| 写入者 | AI 照录**学生原话**，不润色、不替他重排步骤、不代写结论 |
| 章节 | 实践任务 / 课件依据 / 操作步骤 / 现象与报错原文 / 判定 / 通用排查思路 / 我确认的结果 / 保留疑问与待教师确认 / 下一步（缺项写「本轮无」，不删章节） |
| 课件依据 | 找到的表述逐条标 `依据：[[来源页]] §章节`；找不到写「材料未覆盖」 |
| 材料未覆盖的操作报错 | 只在受控例外三项**同时满足**时给通用排查思路，且每条单独成段标注「非课件内容，需教师确认」；仍不联网、不生成课件结论 |
| 掌握度 | 实践**不改** `confidence` / `last_reviewed`；它们只由「复习」时学生的回答更新 |
| 引用 | 每条课件事实性内容标注 `依据：[[来源页]] §章节`；学生自述与课件结论分栏，不混为一类证据 |

## 与相邻目录的分工

| 目录 | 谁在写 | 写什么 |
|---|---|---|
| `wiki/sources/` | 「导入」 | 原始材料的关键要点（可回溯依据） |
| `wiki/concepts/` | 「导入」+「预习」追加「我的理解」 | 概念页与学生本人确认的理解 |
| `wiki/preview/` | 「预习」 | 引导轨迹、学生的原话、保留疑问 |
| `wiki/practice/` | 「实践」 | 操作与现象记录、问题、通用排查思路（标注）、学生确认的结果 |
| `wiki/exam-prep/` | 「出题」/「复习」 | 练习题与费曼复习卡 |

> 实践页**独立成支**：不与「出题 / 复习 / 预习」互相引用，不设教师裁定栏，不新增 `config.md` 配置项。
> 三不（不生成答案、不推测补全、不联网）是「预习」的硬规则，原词与语义不变；受控例外只属「实践」，两处边界独立，互不覆盖、互不放宽。
