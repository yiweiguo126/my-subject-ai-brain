# FAQ

## 名称

**为什么简称要带 AI？**
正式名「我的学科AI大脑」，简称「**学科AI大脑**」。带 AI 是为了标示这一代与旧项目的分界：不是我亲手整理笔记，而是 AI 编译、我来审校与问答。去掉 AI 就退回普通笔记库了。**不要简写成「学科大脑」**。

**「学科」是不是绑定某个专业？**
不是。它指「你自己那门课/那个领域的知识体系」。**模板层零学科、使用层全学科**：底座不含任何课程代码或专业规则，装进去的才是你的学科。大一通识课照样能用。

## 上手

**必须装 Obsidian / Dataview 吗？**
不必须。`Home.md` 是纯 Markdown 静态清单，任何编辑器都能看。装了 Dataview 只是多几个自动面板（用 `FROM #concept` 标签查询，适配 Vault 子目录）。

**AI 工具要打开哪个文件夹？**
打开**本项目文件夹**（含 `AGENTS.md` 的那一层）作为工作空间。如果你的 Vault 根目录另有 `.claude/` / `.agents/`，那些配置作用于整个库，本项目的规则在项目内，只有打开子文件夹才会被自动读取。

**不会命令行 / Git 能用吗？**
能。全程说中文：「初始化」「导入」「预习」「复习」「出题」「体检」「升级」。

**我手头是 PDF / PPT / doc，要怎么放进 `raw/`？**
先在项目外把原始文件转成 `.md`，本人核对内容、按 `L1-主题.md` 命名，**只把 md 放进 `raw/`**；原始文件归档到项目外。完整四步见 `docs/材料准备指南.md`。放完只是材料到位，AI 不会自动处理：① 说「**初始化**」填 `config.md`；② 说「**导入 raw/{课程名}/L1-主题.md**」，一次只点一份；③ AI 给出 3–5 个要点后停下，回「确认」或修正，笔记才生成；④ 逐份重复，打开 `Home.md` 看结果；⑤ 攒到 2–3 份后说「**预习**」。完整路径见 `START-HERE.md`「一次放了好几份 md 怎么办」节。

**能说「把这几份 md 全部导入」吗？**
不能。`skills/wiki-ingest/SKILL.md` 一次只编译一份课件，且 `need_confirm: true` 时明令禁止未经确认批量生成。逐份导入是设计意图：每份材料都要经过你本人把关，这也是「同一份课件长出不同大脑」的起点。

**说「导入」后 AI 停下来不动了？**
那是在等你对要点说「确认」。`need_confirm: true`（`config.md` 默认值）是硬规则，不回应就不会生成任何笔记。可以回「确认」、指出哪条要点不对，或说「改成…」。不建议关闭这个开关。

**转换时容易丢什么，谁负责？**
`raw/` 只放 `.md`，转换由你本人在项目外完成：用本机图形界面工具导出 md，不上传在线服务、不要求命令行。扫描件先在本机 OCR 成可复制文字。最容易丢的是双栏顺序、表格、公式、图示、PPT 备注与 doc 修订；请对照原始文件逐项核对，把关键图示写成文字或表格。**AI 不代你核对转换是否完整，也不推测补全丢失内容**；原始文件归档到项目外，不放进 `raw/`。细则见 `docs/材料准备指南.md`。

**先放了课件才想起没初始化，要重来吗？**
不用。补说一句「初始化」即可，AI 只写 `config.md`，不导入课件、不改 `raw/`（`commands/init.md`）。顺序上先初始化更稳妥，因为 `my_goal` / `language` / `note_style` / `subject_hint` 决定后面笔记怎么写、题怎么出。

## 使用

**同一份文件会重复导入吗？**
不会。`raw/.manifest.json` 记录 md5，hash 相同自动跳过。

**想让 AI 重做一份已导入的材料呢？**
说「**force 重做 `raw/{课程名}/L1-主题.md`**」，一次只指定一份。它只重写 AI 生成的部分：概念页仍只局部补充、不整页覆盖；你写过的「我的理解」原样保留；`confidence` / `last_reviewed` / `Open Questions` 都不动；manifest 里同一路径的条目被覆盖更新，不新增重复条目。`need_confirm: true` 时仍要先确认要点。细则见 `commands/force.md`。

**AI 会改我的课件 md 吗？**
不会。`raw/` 是只读区，AI 永不修改、不改名、不移动、不删除，也不转换其中任何文件。

**一学期有多门课怎么办？**
`raw/{课程名}/` 每门课一个子文件夹，一个副本就够。「预习 / 复习 / 出题」**由你自己带课程名限定**，可指定一门或多门课；不带时按 `config.md` 的 `course_name`。完整口径以 `docs/多课程使用说明.md` 为唯一权威，含 A / B 盘点不跨课与已知限制。

**忘记带课程名会怎样？**
AI 按 `config.md` 的 `course_name` 工作，不会报错。发现范围不对，补一句带课程名的说法即可。课程限定语不是新命令，触发词仍是 12 个。

**图书馆的两份资源文档怎么用？**
`docs/图书馆资源服务指南.md` 按资源类型给框架与流程；`docs/本馆资源获取指南.md` 是馆员填好的本馆入口与合规口径。预习材料不足时先查类型，再查本馆入口；馆员只给获取路径，**不给结论**，材料仍由你本人取得、转换、核对并形成结论。

**升级会不会覆盖馆员填好的本馆指南？**
不会。`docs/本馆资源获取指南.md` 是校本数据，不在升级源中；「升级」只覆盖升级源里同名的白名单文件，不删除本地新增的 docs 文件。见 `commands/upgrade.md`。

**能把原始 PDF 也放进 `raw/` 吗？**
不能。`raw/` 只接受 `.md`。原件与 md 同时放进去，内容相同但 hash 不同，会被当成两份材料、生成两条来源页。「体检」第 17 项会列出非 md 文件，但只提示、不删除；请自行移到项目外。

**导入后能改 md 的文件名或标题吗？**
不建议。`raw/.manifest.json` 以路径为键，改名或移动会让同一份材料被再次导入；标题自动编号会改写 md 正文，让 hash 去重全部失效。确实要重做时说「**强制重做**」。

**为什么文档标题没有数字编号？**
项目不使用章节数字编号，引用章节时写「标题名」节。Obsidian 的标题自动编号插件会改写 `raw/` 源文件，使 `raw/.manifest.json` 里的 hash 全部失效。请保持该插件关闭；这条已写进 `AGENTS.md`「写法约定」。本项目曾在插件生效期间被全库加上编号，现已全部恢复。

**为什么不附标准答案？**
「我的」意味着理解由你完成。练习题只给题目与答题提示，作答区留空；`Open Questions` 也由你自己填。AI 不代答。

**`confidence: low` 是我学得差吗？**
不是成绩，也不排名。它只是「这个概念还没被你讲清楚过」的标记，用来决定复习与出题挑哪些概念。

**AI 写错了怎么办？**
回到 `wiki/sources/` 里指向的原始课件核对，然后让 AI 局部修订概念页。AI 生成内容可能有误，不替代听课与教材。

## 预习

**「预习」和「复习」有什么不同？**
「复习」是检验**你已学过的**内容：AI 提问、你作答，按你的表现更新 `confidence`。「预习」是**入门引导**。它先盘点材料：哪些是新鲜的，哪些已长进你的知识结构。再用 R-CSS 把新知挂到你已有的概念上，帮你建立背景认知、提出更深的问题。预习**不改** `confidence`。

**为什么必须先导入材料？**
因为预习只使用**已导入材料**里的内容。没导入就没有可依据的事实来源，AI 会先请你说「导入」，而不是自己讲一套通用导论。

**材料里没写的，AI 会补吗？会联网查吗？**
都不会。材料无法解答、覆盖不全或不足以支撑结论时，AI 有三条硬约束：**不生成答案、不推测补全、不联网**。它只会建议你自行寻找或上传相关材料，或把问题记进「保留疑问」并提醒向专业老师提问。也可带保留疑问咨询学科馆员；馆员只给馆藏或数据库线索，不给结论。疑问不会被写成结论或概念页。

**有操作 / 实验类任务，能不能让 AI 带着我做？**
说「**实践**」。它逐步记录你**本人**做的步骤、看到的现象和报错，形成独立一支（`wiki/practice/`），不与出题 / 复习互相引用，也不改 `confidence`。AI 是记录员和边界标注员，不替你操作、不替你下课程结论。

**做操作时遇到课件没写的报错，AI 会怎么帮？**
三不（不生成答案、不推测补全、不联网）是「预习」的硬规则，原词与语义不变。课件没写的操作报错属于「实践」场景：三项条件同时满足（问的是操作排查类、材料里找不到、你要的是排查思路而非代做或结论）时，AI 才给通用排查思路，且**每条单独成段标注**：

> ⚠️ 非课件内容，需教师确认：以下只是通用排查思路，课件材料未覆盖；请带到课堂向授课教师确认后再采用，不作为本课程结论。

它仍不联网、不给具体参数或确定结论、不生成课件结论、不改掌握度。两处边界独立，互不覆盖、互不放宽。

**我后来自己找到答案了，怎么入库？**
把新找到的材料放进 `raw/` 说「导入」，或直接把你自己的结论告诉 AI。它会重新盘点、确认依据，再把**你的原话**写进概念页的「我的理解」章节；疑问同时从「保留疑问」标为已解决。AI 不润色、不替你补论证。

**预习会写进知识库的是什么？**
只有三类：**你确认的理解**、**你自己的总结**、**你后来自己想通的解决方案**。AI 的讲解、推断和推测都不会入库。轨迹存 `wiki/preview/`，沉淀追加到已有概念页末尾的「我的理解」章节（局部编辑，不动原页）。

**预习页里的「保留疑问」是不是没答上来就算了？**
不是。它是刻意保留的认知缺口，会在下一轮预习、或你补了材料之后重新被接上。这正是「逐步生长」而非一次生成的意思。

## 测试与清理

**这份为什么是空白模板？**
本分发副本已按下面清单清空测试数据与演示样例，等待第一次「初始化」。若你手上的旧副本曾预置测试填充数据，其规则层仍不含任何学科内容，学科差异只来自 `config.md`。

**怎么清空测试数据，变成空白模板？**

下面是**完整的清理清单**，也是「清空测试数据」命令（`commands/reset.md`）的唯一权威依据。

**A — 数据层（必须清）**

1. 删除 `raw/` 下开发期放入的测试课程文件夹（含 L1 / L2 / L3 三份测试材料；保留 `raw/把课件放这里/`）
2. 删除 `wiki/` 下测试生成的页面：`concepts/*.md`、`courses/*.md`、`sources/*.md`、`exam-prep/*.md`、**`preview/*.md`**、**`practice/*.md`**；各目录的 `_README.md` **保留**
3. 把 `wiki/index.md` / `hot.md` / `glossary.md` / `log.md` 复位为空白模板
4. 把 `wiki/overview.md` / `connections-log.md` / `contradictions.md` 三个占位文件复位为中性占位文字，**不删除**
5. 把 `raw/.manifest.json` 复位为 `{"sources": {}}`
6. 清空 `Home.md` **静态清单**（当前课程、当前状态、课程表、薄弱概念、即将衰减、孤岛、最近更新、入口）；**保留两对** `TEMPLATE:START/END` 标记及其区块
7. 把 `config.md` 的 `course_name` / `subject_hint` 改为空值或目标课程；其余字段不动

**B — 可选演示样例（可留可清，边界见 `docs/教师发放指南.md`「可选演示样例的口径」节）**

8. `examples/` 下 3 份脱敏讲义（L1 / L2 / L3）：全删，或留 1 份作演示
9. `README.md`「当前状态」节、命令表的示例路径：`raw/{课程名}/…` 已是中性写法，改成通用表述即可
10. `Home.md` 模板区：命令表已是中性写法；Dataview 注释里的 `{course-slug}` 换成目标课程标签或删除该行
11. `CHANGELOG.md` 的内部测试段落、`docs/测试记录.md`（教师自查用，可整篇保留）
12. `docs/个性化指南.md`「`subject_hint` 怎么写」小节的两条 `subject_hint` 示例：保留作演示，或换成通用写法
13. `docs/教师发放指南.md`「换课 / 换院系 / 换班」节的「换学科写法」示例（数学 / LaTeX）、「可选演示样例的口径」节的演示样例清单
14. `docs/FAQ.md` 本节（描述测试副本的问答）、`docs/ACCEPTANCE.md` 的样例数量项
15. `raw/把课件放这里/README.md` 的「下一步」示例：`raw/{课程名}/L1-主题.md` 已是中性的 md 写法，无需改

**C — 校本数据与上游文档（保留，不清理）**

16. `docs/本馆资源获取指南.md`：馆员填写的本馆资源获取表，清空测试数据时**保留**；换校发放时由新馆重新填写。`docs/图书馆资源服务指南.md` 与 `docs/多课程使用说明.md` 属上游模板层，同样不清理。

> 也可以直接对 AI 说：「**清空测试数据，复位为空白模板**」。它按本清单列出将改动的文件，**先向你确认**再执行，完成后跑一次「体检」。
> ⚠️ 清理只动数据层与标注为演示样例的内容；`skills/` / `commands/` / `AGENTS.md` / `VERSION` 一律不动。
> ⚠️ 执行前请自行复制一份当前项目作备份，本操作不提供撤销。

**能保留演示样例当演示吗？**
可以，这是**默认选项**。样例正好展示「导入后长什么样」，教师演示时很好用；正式发给学生前按上面 A、B 两组清单清空即可。规则层（`AGENTS.md` / `skills/` / `commands/`）始终零学科，说明层与样例层含演示内容不影响换课。

## 升级与维护命令

**收到新版，怎么升级？**
从图书馆版本页 / GitHub Releases 获取新版，把 ZIP 解压到**当前项目文件夹之外**的同级目录（例如 `../我的学科AI大脑_v1.00/`），然后说「**升级**」并告诉 AI 路径。版本发布、hash 清单与历史版归档由图书馆保管，见 `docs/升级指南.md`。不要把新版直接覆盖当前项目。AI 只从新版目录读取底座文件，替换白名单，最后用 hash 证明你的 `raw/` / `wiki/` / `config.md` 没变。详见 `docs/升级指南.md` 与 `commands/upgrade.md`。

**升级后「体检」说版本不一致，是坏了吗？**
不是。升级按约定跳过 `config.md`，所以从 v1.00 起里面的 `version` 会落后于 `VERSION`。体检把它标为**预期告警**，提示你核对 `CHANGELOG.md`，不要求手改配置。见 `config.md`「version 与体检告警」小节。

**`CHANGELOG.md` 提到页面格式迁移，要做什么？**
看过升级报告后主动说「**迁移**」。AI 先列出待迁移页面和字段预览，你确认后才逐页局部调整 frontmatter；不改正文、不改「我的理解」、不改 `confidence`。见 `commands/migrate.md`。

**「清空测试数据」和「升级」有什么区别？**
前者按「测试与清理」节清单把当前副本复位成空白模板，会删除数据层内容，执行前必须确认并自行备份；后者只换底座，不删任何学生内容。两者互不调用。

## 分发与隐私

**教师或图书馆会看到我的笔记吗？**
不会。数据留在本机，不上传、不收交、不比较、不排名。教师只反馈使用情况，图书馆只汇总匿名指标，都不看 `wiki/` 与 `confidence`。

**一学期多门课要重新下载吗？**
不用。一个副本放多门课的材料，命令带课程名限定即可，见 `docs/多课程使用说明.md`。

**能按院系做不同版本吗？**
不建议，也没必要。差异放 `config.md`，**一份包服务所有班**，仓库分支数保持 1。
