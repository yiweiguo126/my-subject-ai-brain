# 个性化指南

> **唯一入口：`config.md`。** 它决定「这个学科AI大脑按谁的方式长」。
> 升级模板时**永不覆盖**这个文件。

## 🟢 自由改（改完直接生效）

打开 `config.md`，改 YAML 区里的值即可，不用告诉 AI、不用重启。

| 字段 | 可以改成 | 效果 |
|---|---|---|
| `course_name` | 任意课程名 | 页面标签、文件夹命名 |
| `my_goal` | `听懂` / `应试` / `做项目` / `写论文` | ★ 概念页详略 + 出题方向全变 |
| `language` | `中英双语` / `纯中文` / `纯英文` | 标题与术语语言 |
| `note_style` | `费曼式` / `应试型` / `极简型` | 概念页写法 |
| `review_cycle_days` | 正整数，0 = 关闭 | 多少天没复习就提示衰减 |
| `exam_prep` | `true` / `false` | 是否生成练习题 |
| `need_confirm` | `true` / `false` | 导入前是否先确认（建议保持 `true`） |
| `subject_hint` | 任意自由文本 | 学科写作提示 |
| `ai_tool` | 任意文本 | 记录用的工具，方便答疑 |

### `my_goal` 是最值得改的一项

| 取值 | 概念页侧重 | 出题方向 |
|---|---|---|
| `听懂` | 直觉解释 + 生活化类比 + 为什么重要 | 概念辨析、举反例 |
| `应试` | 定义 + 要点清单 + 易错点 | 简答、名词解释、对比题 |
| `做项目` | 适用条件 + 操作步骤 + 常见坑 | 情境应用、方案设计 |
| `写论文` | 理论脉络 + 争议点 + 可引用来源 | 文献评述、论证重构 |

### `subject_hint` 怎么写

模板**不预设任何学科**，这是你告诉 AI「这门课该怎么写」的地方：

```yaml
subject_hint: "<学科名>：概念配案例与反例；流程/框架优先用 Mermaid 图；术语中英对照"
```

```yaml
subject_hint: "<学科名>：公式用 LaTeX，每个符号配直觉解释，定理标明适用条件"
```

留空就用通用学术写法。**这里的内容不会进底座**，换一门课改这一行即可。
一学期多门课时，`config.md` 仍是单值：整段时间换课改两行，临时查另一门课用课程限定语。完整口径见 `docs/多课程使用说明.md`。

### 「预习」会读哪些设置

预习不会改你的 `config.md`，只读以下字段来决定引导方式：

| 字段 | 在预习里的作用 |
|---|---|
| `course_name` | 预习页命名与标签 |
| `my_goal` | ★ 提问风格：听懂→类比复述；应试→定义辨析；做项目→适用条件；写论文→材料里的依据与争议 |
| `language` / `note_style` | 引导用词与解释方式 |
| `subject_hint` | 学科写法提示（只影响表达，不增加材料之外的内容） |
| `need_confirm` | 沉淀前是否先回显确认 |

`exam_prep`、`review_cycle_days` 与预习无关。**预习不会改 `confidence`**，也不新增任何配置项 —— 个性化仍然只有一个入口。

「实践」同样只读上述现有字段（用 `course_name` 命名、`subject_hint` 影响写法、`need_confirm` 决定是否回显确认），**不新增配置项、不改 `confidence`**。

## 🟡 慎改（改前跑「体检」）

- 概念页 frontmatter 字段
- 命令别名
- 自定义页面模板

升级前会自动备份为 `config.backup.md`。改完说「**体检**」确认合法。

## 🔴 不可改

| 对象 | 原因 |
|---|---|
| 三层架构与目录名 | 写入契约，改了去重/索引/互链全失效 |
| `skills/`、`commands/` | 共同底座，升级会覆盖 |
| `AGENTS.md` | 主契约 |
| `manifest/hot/index/log` 格式 | AI 依赖的结构 |
| `VERSION` | 版本标识 |

## 个体差异从哪来

同一个包、同一份课件，长出的学科AI大脑也不同，因为：

1. 你**导入什么**（课件、补充材料、自己的笔记）
2. `config.md` **怎么设**（尤其 `my_goal` 与 `subject_hint`）
3. 复习时**你怎么答** → `confidence` / `last_reviewed` 是个人掌握度
4. 你**卡在哪** → 概念页 `Open Questions` 由你填
5. 你**怎么连** → 跨讲次连接与薄弱点随理解路径形成

> 模板层完全一致，数据层人人不同。这正是「一份包不产生副本」与「个体差异性」能同时成立的原因。

## 常见问题

**改了 `my_goal`，之前生成的笔记会变吗？**
不会自动重写。新导入的课件按新目标生成；想重做旧的可对 AI 说「按新目标补充 `{概念页}`」。

**`need_confirm` 能关吗？**
可以，但不建议。导入前确认是「AI 编译、人把关」的关键环节。

**教师能看到我的 `config.md` 吗？**
不能。数据留在本机，不收交、不比较。
