# 图书馆资源服务指南

> **性质**：上游空白框架。本文件不含任何具体馆名、数据库产品名、网址与账号。
> 馆员把本馆信息填进 `docs/本馆资源获取指南.md`，那份文件随包发给学生。
> 流程与边界以本文件为唯一权威；填写表只承载本馆信息，不重复流程。
> 三条底线：AI 不联网；馆员只给获取路径、不给结论；材料由学生本人取得、转换、核对并形成结论。

## 谁填、什么时候填

| 项 | 规定 |
|---|---|
| 谁填 | 本馆学科馆员或参考咨询馆员 |
| 何时填 | 立项时填一次；每学期复核一次 |
| 填在哪 | `docs/本馆资源获取指南.md` |
| 谁保管 | 图书馆。该文件是校本数据，不在升级源中 |
| 何时改 | 本馆入口、许可范围或引用规范变化时 |

本文件由上游维护，随 `docs/**` 白名单升级。馆员填写的内容不进上游 `VERSION`。

## 学生怎么用

1. 「预习」发现材料没覆盖，把问题记进「保留疑问」。
2. 查 `docs/本馆资源获取指南.md`，找到对应资源类型与本馆入口。
3. 到馆或按本馆许可自行取得**本人有权使用**的片段。
4. 按 `docs/材料准备指南.md` 在项目外转成 md，本人核对、命名、放进 `raw/{课程名}/`。
5. 说「导入」，再回到「预习」重新盘点；自己得出结论后才沉淀。
6. 学科结论带回课堂，请任课教师确认。

> 馆员不代找答案、不代取全文、不代转 md、不代下结论。AI 三不（`AGENTS.md` 硬规则第 9 条）不因本指南放宽。

## 资源类型与判定原则

下表按**资源类型**给框架，不写具体产品名。每类在本馆对应什么入口、怎么取得，由馆员填进填写表。

| 资源类型 | 典型用途 | 转成 md 放进 `raw/` 的判定原则 |
|---|---|---|
| 教材与教学参考书 | 课前背景、补材料 | 只取本人依法可用的片段；整书不进 `raw/` |
| 电子书与电子教材平台 | 课前背景 | 先看章节下载与复制许可 |
| 中外文学术期刊数据库 | 预习缺口、写论文 | 禁止批量下载；禁止把整库或整期全文入库 |
| 学位论文、会议论文、报告、标准、专利 | 写论文、做项目 | 核对使用许可与公开范围 |
| 多媒体与图像资源 | 图示转文字 | 图片只作附件，不作事实来源 |
| 开放资源（开放获取、开放教材、机构库、开放数据） | 补材料首选 | 核对许可版本与可引用范围 |
| 馆际互借与文献传递 | 本馆未藏时 | 遵守传递件的使用范围 |
| 特藏与本校特色资源 | 校本题材、写论文 | 遵守复制与公开限制 |
| 事实与工具型资源（辞典、年鉴、统计、规范、词表） | 术语与判据 | 只作辅助，不作学科结论 |

## 从资源到 raw 的六步

**找 → 判 → 取 → 转 → 核 → 导入**，一次只处理一份材料。

- 判：先看授权与可信度，再看是否覆盖「保留疑问」的缺口。
- 转：在项目外用本机图形界面工具导出 md，不上传在线服务。
- 核：对照原件逐项核对表格、公式、图示，见 `docs/材料准备指南.md`。
- 命名：`L{讲次}-主题.md`；来源页可选 `original_file` 记原件与归档位置。
- 导入：说「导入」并带完整路径，先确认要点，见 `commands/ingest.md`。

## 检索任务单

模板与空表在 `docs/本馆资源获取指南.md`。分工固定：

| 谁 | 填到哪 |
|---|---|
| 学生 | 疑问编号、来自哪份预习页、涉及概念、缺口类型、自取结果、自己的结论 |
| 馆员 | 推荐资源类型、建议检索词、**本馆获取路径**（到此为止） |
| 教师 | 学科结论是否成立 |

馆员填完「本馆获取路径」即交接，不代填学生的结论列。任务单不含学生 `wiki/` 内容。

## 合规清单（馆员填本馆口径）

- 课件使用授权、AI 生成内容标注规范
- 数据库许可中的下载、复制与入库限制
- 不用在线转换服务上传课件
- 不收集、不查看、不比较学生 `wiki/` 与 `confidence`
- 学生数据留在本机

## 服务台记录

只记匿名人次与问题类型，不含姓名、学号、笔记内容。空表见填写表。

## 版本与共商

图书馆负责发布 ZIP、版本升级与历史版本保管；教师反馈使用情况；双方期末共商版本变更议题。
流程见 `docs/升级指南.md`「图书馆怎么发新版与保管版本」节，议题表见 `docs/FEEDBACK.md`「版本变更议题表」节。
课程资料、学科写法卡与本馆资源获取表的更新属于**服务层内容**，不进 `VERSION`。
