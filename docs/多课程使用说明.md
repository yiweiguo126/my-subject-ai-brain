# 多课程使用说明

> **本文是「一学期多门课怎么用」的唯一操作权威**。其他文件只引用，不另给口径。
> 路线 A：`config.md` 结构、命令表、页面格式、目录与升级白名单**全部不改**。
> `docs/图书馆资源服务指南.md` 与 `docs/本馆资源获取指南.md` 属服务层，不受课程数影响。

## 现状：数据层已支持，配置层是单值

| 已经支持多课程 | 仍是单值 |
|---|---|
| `raw/{课程名}/` 每门课一个文件夹 | `config.md` 的 `course_name` |
| `wiki/courses/{课程名}-overview.md` 每门课一页 | `my_goal` / `subject_hint` / `language` / `note_style` |
| 概念页 `courses:` 是数组，可挂多课 | `review_cycle_days` / `exam_prep` / `need_confirm` |
| `raw/.manifest.json` 以完整路径为键，每条带 `course` | `wiki/hot.md` 是一份全局缓存 |
| 来源页、预习页按课程名命名 | |

结论：**一个副本放多门课的材料可以；一门课一套配置做不到**。因此用「课程限定语」在每次会话里指定范围。

## 目录怎么放

```text
raw/{课程名A}/L1-主题.md
raw/{课程名B}/L1-主题.md
```

文件夹名用课程名，不带空格与特殊字符。每份 md 仍按 `L{讲次}-主题.md` 命名，导入后不改名、不移动。
教师发的 PDF / PPT / doc 仍要由学生本人转成 md、核对后再放，见 `docs/材料准备指南.md`。

## 课程限定语（核心）

**它不是新命令**。触发词仍以 `AGENTS.md`「命令映射」表为唯一权威，共 12 个。
在「预习 / 复习 / 出题」后面直接带课程名，可指定**一门或多门课**；「实践」也带课程名，但按一门课分别记录、不跨课混写：

| 说法 | 作用范围 |
|---|---|
| `预习 {课程名A}` | 只盘点该课的 A / B 材料 |
| `复习 {课程名A} 第三章` | 只问该课该章的概念 |
| `出题 {课程名A}` | 只挑该课 `low / medium` 概念 |
| `出题 {课程名A} + {课程名B}` | 两门课各出一组，分别标注 |
| `预习 全部课程` | 按课分别盘点，逐课推进 |

带课程名时：AI 只在 `raw/{课程名}/` 与 `wiki/` 中 `course` / `tags` 匹配的页面范围内工作。
不带课程名时：按 `config.md` 的 `course_name`。
「预习」的 A / B 盘点**按课分别进行，不跨课挂接锚点**：不能把甲课的概念当乙课的认知起点。
`config.md` 不因此被改写；`confidence` / `last_reviewed` 仍属于概念页本身，不按课程另存。
「导入」始终带完整路径，一次一份，不受课程限定语影响。

## 切换主线的两种情况

| 情况 | 做法 |
|---|---|
| 整段时间只学另一门课 | 手改 `config.md` 的 `course_name` 与 `subject_hint` 两行 |
| 临时查另一门课 | 用课程限定语即可，不必改配置 |

改 `subject_hint` 只影响**之后新导入**的材料写法；已有页面不自动重写。学科写法卡由图书馆侧提供可选文本，学生自己填，见 `docs/图书馆资源服务指南.md`。

## 已知限制（路线 A 的代价）

- `wiki/hot.md` 是全局 ≤500 词缓存，多课并行时可能混入另一门课的内容。提问务必带课程名，并核对每条「依据：来源页 §章节」。
- 「复习」与「出题」不带课程名时，会把全部 `low / medium` 概念混在一起。
- `wiki/index.md`、`glossary.md`、`log.md` 与 `Home.md` 静态清单未按课程分组，靠页面自带的 `course` / `tags` 区分。
- 这些限制不靠新增配置项解决。若以后确需课程级配置，属于架构升级，不属本版范围。

## 常见问题

**能同时学多门课吗？**
能。材料各放各的文件夹，命令带课程名即可。一次会话建议限定一门课，范围最清楚。

**忘记带课程名会怎样？**
AI 按 `config.md` 的 `course_name` 工作，不会报错。发现范围不对，补一句带课程名的说法即可。

**同一份课件在两门课都要用，要放两份吗？**
不要。`raw/.manifest.json` 以路径为键，两份同内容文件会生成两条来源页。放一份，在概念页 `courses:` 里标两门课。

**`raw/` 下能放多少门课？**
不限。前提仍是只放 md、单文件导入、导入前确认。

## 边界

- 课程限定语不新增命令、不改页面格式、不改 `config.md` 结构
- 不按课程 / 院系 / 班级开分支；仓库分支数保持 1
- AI 三不、不收交不比较不排名、数据层永不覆盖，均不因多课程放宽
