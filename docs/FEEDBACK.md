# FEEDBACK — 期末匿名反馈模板

> 用途：一学期试点结束时收一次匿名反馈。**只问四件事**，不收集学生笔记、不收集 `wiki/` 内容、不排名。
> 谁用：图书馆发布并汇总匿名问卷；**教师反馈使用情况**；双方期末共商版本改动与升级方案。

## 反馈怎么用（硬边界）

- 反馈**只回写底座**（`AGENTS.md` / `skills/` / `commands/` / `docs/`）或 `config.md` 的**默认值**
- **不按**课程 / 院系 / 班级开分支、不做专属副本；仓库分支数保持 1
- **不收集**学生 `wiki/`、`raw/`、`Home.md` 静态清单与 `confidence`
- 涉及页面格式变化时，在 `CHANGELOG.md` 写明迁移说明，学生说「**迁移**」后才执行（`commands/migrate.md`）
- 按版本变更议题表的**双方决议**发版；`CHANGELOG.md` 用大白话写「改了什么、你要做什么」
- 课程资料、学科写法卡与本馆资源获取表的更新属服务层内容，不进 `VERSION`

## 归档

汇总表与议题表填完后，把结论写进 `CHANGELOG.md` 的「下一版判断依据」。
本表、hash 清单、每版 ZIP 与历史版本由**图书馆**归档保管；本表留档一学期。
