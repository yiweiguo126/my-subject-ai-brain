# 材料准备指南

> **使用前提**：先把原始文件处理成 Markdown，**`raw/` 里只存放 `.md` 文档**。
> 本文是这一步的唯一操作说明；规则以 `AGENTS.md` 硬规则第 10 条为准。

---

## 为什么先转 md

- 任何 AI 工具都能读纯文本，不再依赖「这个工具能不能直读本地 PDF」
- Obsidian 里可以直接查看、全文搜索、建立双向链接
- md 的标题层级让 `wiki/` 里的「依据：`[[来源页]]` §章节」能定位到具体位置
- PDF / PPT / doc 原本格式各异，转成 md 后只有一个入口；PPT 与 doc 此前不在支持范围内

## 谁转、在哪转

| 事项 | 规定 |
|---|---|
| 谁转 | 学生本人；教师可提前转好 1 份作课堂演示 |
| 在哪转 | **项目文件夹之外**。转换完成后只把 md 放进 `raw/` |
| 用什么 | 本机、图形界面、不上传；不要求装命令行 / Git / IDE / 插件 |
| 原始文件 | 归档到项目外，**不放进 `raw/`** |
| AI 的角色 | 不转换文件、不导入非 md 文件、不代你核对转换是否完整、不推测补全丢失内容 |

> ⚠️ **不要用在线转换服务上传课件**。数据留本机、不上传是项目红线，见 `README.md`「使用提醒」节与 `docs/教师发放指南.md`「合规清单」节。

## 图书馆能帮你什么

材料不足时，图书馆提供的是**资源线索与规范**，不是答案：

- 按 `docs/图书馆资源服务指南.md` 的资源类型框架判断该找哪类材料
- 查 `docs/本馆资源获取指南.md` 里馆员填好的本馆入口、获取方式与引用要求
- 带「保留疑问」咨询学科馆员；馆员**只填到获取路径**，不代找结论、不代取全文、不代转 md
- 学生本人取得有权使用的片段，再按下面四步转成课件 md；学科结论带回课堂请教师确认

> 教师发下来的 PDF / PPT / doc 同样由学生本人转换与核对，AI 不代核、不补、不猜。

## 四步做完

### 转换

把 PDF / PPT / doc / 扫描件导出为 `.md`，保留原有的标题层级与段落顺序。扫描件先在本机 OCR 成可复制的文字，再导出 md。

### 核对

转换质量由**你本人**负责。逐项对照原始文件检查：

- [ ] 标题与段落顺序完整，没有漏页、乱码、错行
- [ ] 表格没有塌成一串文字
- [ ] 公式、符号、上下标可读；读不懂的部分自己修好
- [ ] 关键图示已写成文字描述或表格；图片只作附件，**不作事实来源**（AI 读不到图）
- [ ] PPT 的图示与演讲者备注、doc 的修订与批注，需要的内容已转进正文

转换中丢失的内容由你对照原始文件修好 md 后再导入。AI 不代核、不补、不猜。

### 命名

放进 `raw/{课程名}/`，文件名用「讲次 + 主题」：

```text
raw/{课程名}/L1-主题.md
raw/{课程名}/L2-主题.md
```

避免空格与特殊字符。**导入后不要改名、不要移动**：`raw/.manifest.json` 以路径为键，改名会让同一份材料被再次导入。确实要重做时说「**强制重做**」。

### 放入并导入

只把 md 放进 `raw/{课程名}/`，然后对 AI 说：

```text
导入 raw/{课程名}/L1-主题.md
```

一次一份。AI 给出 3–5 个要点后会停下来等你确认，确认后才生成来源页与概念页。多份材料的处理方式见 `START-HERE.md`「一次放了好几份 md 怎么办」节。

## 转换之后不要再改

- **不要启用 Obsidian 的标题自动编号**：它会改写 md 正文，让 `raw/.manifest.json` 的 hash 去重失效，见 `docs/FAQ.md`「为什么文档标题没有数字编号」
- **不要改名或移动**：理由见上一步
- **不要把原始文件与 md 一起放进 `raw/`**：内容相同但 hash 不同，会被当成两份材料，生成两条来源页
- 升级只换底座，`raw/` 与 `wiki/` 永不覆盖

## 引用怎么回溯

课件 md 是原始文件的派生物，回溯链因此多了一环：

```text
概念页 → wiki/sources/ 来源页 → raw/ 里的课件 md →（可选）项目外的原始文件
```

来源页 frontmatter 的 `source_file` 指向 `raw/` 里的课件 md；新增的**可选**字段 `original_file` 用来记原始文件名与项目外的归档位置。这个字段不填也行，不影响导入，也不触发「迁移」。

## 常见问题

**转换丢了表格或公式怎么办？**
你本人对照原始文件把 md 修好，再重新导入。AI 不补、不猜、不联网。

**扫描件怎么办？**
先在本机 OCR 成可复制的文字，再导出 md；OCR 结果同样要本人核对。

**教师能提前转好吗？**
可以。把转好的 md 作为本班样例发给学生，但不要替学生填 `wiki/`：同一份模板要长出每个人自己的大脑。

**把 PDF 直接放进 `raw/` 会怎样？**
「导入」会停止并提示先按本指南转换；「体检」第 17 项会列出非 md 文件，但**只提示、不删除、不转换**。请自行把它移到项目外。

**一次放了好几份 md 怎么办？**
逐份说「导入」，每份都要确认要点。不要说「把这几份全部导入」。

## 边界

- 本指南只讲**文件格式**，不预设任何学科写法；模板层零学科
- 转换质量与理解都由你本人负责；AI 生成内容可能有误，不替代听课与教材
- `raw/` 是只读区，AI 永不修改、不改名、不移动、不删除、不转换其中任何文件
