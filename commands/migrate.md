# 命令：迁移 / migrate

**触发**：「迁移」「migrate」「按新版格式调整页面」。

> 这是**唯一**允许 AI 改写 `wiki/` 已有页面结构的命令。只在 `CHANGELOG.md` 给出迁移说明时可用。

## 前置条件（缺一即停止）

1. `CHANGELOG.md` 明确写出「页面格式变化 + 迁移说明」
2. 学生已收到新版并用「升级」换过底座
3. 学生明确说「**迁移**」或确认执行

条件不满足时只回复：「当前版本没有需要迁移的格式变化」，不做任何改动。

## 允许改什么

| 允许 | 不允许 |
|---|---|
| 概念页 / 来源页 / 预习页的 frontmatter 字段名与字段值格式 | 正文内容、学生原话、「我的理解」章节 |
| 按迁移说明补齐缺失字段 | `confidence` / `last_reviewed` |
| 局部编辑，逐页处理 | `Open Questions`（不代填）、保留疑问 |
| 最后一次性更新 `wiki/index.md` `hot.md` `log.md` | `raw/` 下任何文件、`config.md`、`Home.md` 静态清单 |

## 流程

1. 读 `CHANGELOG.md` 的迁移说明，列出**待迁移页面清单 + 每页改动的字段预览**
2. 把清单交给学生，等学生确认；不确认就停止
3. 逐页做 frontmatter 局部替换，不重写整页
4. 记录本次迁移到 `wiki/log.md`
5. 跑一次「**体检**」，核对 frontmatter 完整性与数据层 hash
6. 输出报告：迁移了哪些页、改了哪些字段、未碰哪些内容

## 失败处理

任一步失败即停止，保留已完成页的迁移记录，并在报告里列出未完成页，等学生决定重跑。不得生成统一标准答案页，不得替不同学生统一结构。

## 与其他命令的边界

- 「升级」只换底座，**不调用**本命令；由学生在看过升级报告后主动说「迁移」
- 「清空测试数据」用 `commands/reset.md`；「强制重做」用 `commands/force.md`
