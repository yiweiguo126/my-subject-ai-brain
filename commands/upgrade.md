# 命令：升级 / upgrade

**触发**：「升级」「upgrade」「更新模板」。

> 一句话：**换的是共同底座，不动任何一个人的学科AI大脑。**

## 升级源路径（先做这一步）

1. 从**图书馆版本页 / GitHub Releases** 获取新版 ZIP，解压到**当前项目文件夹之外**的同级目录，例如 `../我的学科AI大脑_v2.00/`。
2. **不要**把新版直接解压覆盖当前项目。
3. 说「**升级**」并告知解压后的路径；未给路径时按 `../我的学科AI大脑_v2.00/` 查找。
4. AI 只从升级源**读取**白名单文件；升级源目录只读，不写入、不删除、不解包到 `raw/` 或 `wiki/`。
5. 找不到升级源，或 `VERSION` 未变大：停止并报告，不替换任何文件。

## 白名单（可替换）

| 路径 | 说明 |
|---|---|
| `skills/**/*` | 8 个 SKILL.md（含 `preview`、`practice`） |
| `commands/**/*` | 12 个命令文件（含 `preview.md`、`practice.md` 与 3 个维护命令） |
| `AGENTS.md` | 主契约（硬规则、命令表、术语表） |
| `Home.md` 模板区 | 仅替换每一对 `<!-- TEMPLATE:START -->` 与 `<!-- TEMPLATE:END -->` 之间的区块；当前有 2 处（命令速查表、可选增强） |
| `README.md` `START-HERE.md` | 说明与上手文档（含版本落点，随底座升级） |
| `快速上手.html` | 静态说明卡（无状态，随底座升级） |
| `脑回路生长图.html` | 只读看板；**升级只替换 HTML 骨架（含内联纯渲染脚本），`<script id="dashboard-data">` 数据块内容保留原值**（见「流程」节第 4 步） |
| `docs/**/*` | 使用说明 |
| `examples/**/*` | 可选演示样例 |
| `VERSION` `CHANGELOG.md` `LICENSE` `ATTRIBUTION.md` | 版本与许可 |

> **升级只覆盖升级源中同名的白名单文件，不删除本地新增的 docs 文件。**
> `docs/本馆资源获取指南.md` 是馆员填写的校本数据，**不在升级源中**，升级不覆盖、不删除；由图书馆自行维护。
> `脑回路生长图.html` 的数据块是学生状态的**只读投影**，升级换骨架时须先读出、替换后原样写回，只更新 `brain_version`，不得当作可覆盖的模板内容清空。骨架含内联纯渲染脚本，属模板层，可随骨架替换；脚本只读内嵌数据块、不联网、不写入。

## 永不触碰（数据层）

- `raw/**` —— **全部**，含 `.manifest.json`
- `wiki/**` —— **全部**，学生的学科AI大脑（含 `wiki/practice/` 实践记录，永不覆盖）
  - **唯一受控例外**：v2.00 起，若本地 `wiki/connections-log.md` 头部仍为 v0.1 占位声明，只把该头部说明块替换为升级源的格式说明，**保留文件内全部已登记连接**；`wiki/index.md` 占位节由下一次「导入」局部刷新，升级不主动改写。此例外不改动任何学生内容。
- `config.md` —— 个体设置，不覆盖、不回写
- `Home.md` 模板区之外的静态清单
- `docs/本馆资源获取指南.md` —— 校本数据（馆员填写的本馆资源获取表）

> `config.backup.md` 是「流程」节第 3 步由升级流程生成的**备份文件**，由升级流程维护。它不属于「覆盖学生设置」，也不是学生要改的文件。

> **版本口径**：升级按约定跳过 `config.md`，因此 `config.md:version` 与 `VERSION` 会不一致。这是预期结果，体检第 8 项按「预期告警」报告，不判为底座异常，也不要学生手改（见 `config.md`「version 与体检告警」小节）。

## 流程

1. 确认升级源路径与新版 `VERSION`
2. 升级前跑一次「**体检**」，记录 `raw/` + `wiki/` + `config.md` 的文件 hash
3. 备份 `config.md` 为 `config.backup.md`
4. 只替换升级源中同名的白名单文件；`Home.md` 只换模板区；不删除本地新增的 docs 文件。
   **替换 `脑回路生长图.html` 前，先读出其 `<script id="dashboard-data">` 数据块内容；用升级源骨架替换整页后，把该数据块原样写回，只把 `brain_version` 更新为新版本号。**数据块字段一律不重新计算、不清空——它是学生状态的只读投影，不是模板内容。若数据块为 `dashboard-data/v1`，渲染器显示生长视图空态，下一次末尾更新时由 AI 从真相源重建并升为 v2；若本地尚无 `脑回路生长图.html`（旧版本升级），直接采用升级源骨架与其空白数据块。
   **按「永不触碰」节的唯一受控例外**处理 `wiki/connections-log.md` 头部声明迁移。
5. 更新 `VERSION` 与 `CHANGELOG.md`
6. 升级后再跑一次「**体检**」，核对 hash **未变**（含脑回路生长图数据块：除 `brain_version` 外字段须与升级前一致；含内联渲染脚本无联网 / 无写入 / 无外链）
7. 输出报告：「换了哪些 / 没碰哪些 / 需要你做什么」

## 失败处理

任一步失败即停止并回滚到备份，**不得**留下半个升级状态。
回滚范围只限本次替换过的白名单文件；`raw/`、`wiki/`、`config.md` 全程不参与回滚写入。

## frontmatter 格式变化

**「升级」不直接改 `wiki/`。** 若 `CHANGELOG.md` 给出页面格式迁移说明，升级报告里提示学生说「**迁移**」，再加载 `commands/migrate.md` 执行，且必须学生确认。
