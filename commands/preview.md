# 命令：预习 / preview

**触发**：学生**已导入课件 md**后说「预习」「我想了解一下…」「这门课在讲什么」「先带我入门」「新知识怎么跟我学过的接上」「preview」。可带课程限定语，指定一门或多门课。

→ 加载 `skills/preview/SKILL.md`，按 R-CSS 阶段闸门执行。

**前置**：`raw/` 有课件 md、`wiki/` 有对应来源页与概念页、至少有 1 个可作锚点的已有概念。缺任一项则只提示先说「导入」，不展开引导。**带课程名时按该课范围检查；不带时按 `config.md` 的 `course_name`**。范围规则见 `docs/多课程使用说明.md`。

**必做顺序**（一步一动作）：

1. 材料盘点：区分 A 已有知识结构与 B 新鲜材料。
2. 学生确认盘点结果与锚点。
3. R-CSS 引导：每段标注材料出处，挂到已有概念。
4. 材料不足守门。
5. 只沉淀学生本人确认的理解、自行总结、自得结论。
6. 最后一次性更新 `index` / `hot` / `log`，并同步写 `驾驶舱.html` 数据块（只读投影，字段派生自真相源，不改掌握度、不写 AI 讲解或保留疑问为结论；增量追加 `timeline` / `graph` / `milestones` 生长数据，不登记连接；契约见 `AGENTS.md`「驾驶舱（只读投影）」节）。

**材料不足时**：执行三不 —— **不生成答案、不推测补全、不联网**；只建议自行寻找或上传材料（先转成 md；可咨询学科馆员获取馆藏或数据库线索，馆员只给获取路径、不给结论）、标记保留疑问并提醒课上向专业老师提问、等待学生形成结论；疑问不入库，待用户形成结论后再入库。资源类型框架见 `docs/图书馆资源服务指南.md`。

**禁止**：联网检索、推测补全、替学生作答或总结、改 `confidence`、把保留疑问写成结论、修改 `raw/`、覆盖 `config.md`、替未导入文件编译概念页。
