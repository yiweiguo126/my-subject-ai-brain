# 命令：实践 / practice

**触发**：学生在操作软件/工具、跑实验、做练习、做项目或调试报错时说「实践」「实操」「动手做」「这一步怎么操作」「这个报错怎么办」「我照着做卡住了」「这里报错了」「怎么排查」「practice」。可带课程限定语，指定一门课。

→ 加载 `skills/practice/SKILL.md`，按编号步骤逐步记录。

**前置**：`raw/` 有本学科课件 md 且已导入；学生正在做一次真实操作，有可记录的步骤、现象或报错；学生要的是记录与排查思路，不是替他完成操作或给课程结论。缺任一项则只提示先说「导入」或说明边界，不展开。带课程名时按该课范围记录；不带时按 `config.md` 的 `course_name`。范围规则见 `docs/多课程使用说明.md`。

**必做顺序**（一步一动作）：

1. 在全部已导入材料中查找该操作 / 报错的对应表述，逐条记 `依据：[[来源页]] §章节`；找不到写「材料未覆盖」。
2. 记录学生操作步骤（原话）与现象 / 报错原文（原样），不润色、不替他重排。
3. 判定：有课件依据 → 只引用课件表述；无依据 → 检查是否同时满足受控例外三项条件。
4. 三项同时满足 → 只给通用排查思路（核对前提 / 复现步骤 / 读报错原文 / 缩小范围 / 回退上一步 / 记录现象供教师判断），每条单独成段附标注话术原文。
5. 不满足（要概念结论 / 要代做 / 要具体参数值）→ 不排查，提示补材料或课上问老师；概念结论类回到「预习」三不，不放宽。
6. 写入实践页各节（含学生确认的结果与待教师确认清单），末尾一次性更新 `index` / `hot` / `log`，并同步写 `驾驶舱.html` 数据块（只读投影，只记 counts.practice/recent、不聚合实践为课程结论、不改掌握度；增量追加 `timeline` / `graph` / `milestones` 生长数据，不登记连接；契约见 `AGENTS.md`「驾驶舱（只读投影）」节）。

**问题处理时**：课件没写的操作报错，只在受控例外三项同时满足时给通用排查思路，且每条单独成段标注「> ⚠️ 非课件内容，需教师确认：以下只是通用排查思路，课件材料未覆盖；请带到课堂向授课教师确认后再采用，不作为本课程结论。」三不是「预习」的硬规则（不生成答案、不推测补全、不联网），原词与语义不变；受控例外只属「实践」，仍不联网、不生成课件结论、不改 `confidence`，两处边界独立，互不覆盖、互不放宽。

**禁止**：联网、给具体参数值或确定结论、替学生完成操作、省略或改写标注话术、把排查思路写成课程结论、把学生自述与课件结论混为一类证据、改 `confidence`、设教师裁定栏、打通出题 / 复习引用、修改 `raw/`、覆盖 `config.md`、新增 config 配置项。
