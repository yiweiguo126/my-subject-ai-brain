# 把课件 md 放这里

这里是 `raw/` —— **只读区**。**只存放 `.md` 文档**：手头的 PDF / PPT / doc 等原始文件先在项目外转成 md，本人核对、命名后再放进来。

## 规则

- AI **永不修改**这个目录里的任何文件（不改名、不移动、不删除、不转换）
- 原始文件（PDF / PPT / doc）**不要放进 `raw/`**，归档到项目外
- 命名：`raw/{课程名}/L1-主题.md`、`raw/{课程名}/L2-主题.md`，讲次 + 主题
- **每门课一个子文件夹**：`raw/{课程名A}/`、`raw/{课程名B}/`；用法见 `docs/多课程使用说明.md`
- 同一份文件不会被重复导入（用 `raw/.manifest.json` 记录 md5）
- 不要启用 Obsidian 的标题自动编号：它会改写 md 正文，让 hash 去重失效
- 导入后不要改名或移动文件；确实要重做时说「**强制重做**」
- 转换中丢失的表格、公式、图示由你本人对照原始文件修好；AI 不代核、不补、不猜

## 下一步

放好 md 后，对 AI 说：「**导入 raw/{课程名}/L1-主题.md**」，一次一份。

> 转换、核对、命名与原件归档的完整说明见 `docs/材料准备指南.md`。
> 预习发现材料不足时，按 `docs/图书馆资源服务指南.md` 找资源类型，本馆入口见 `docs/本馆资源获取指南.md`。馆员只给获取路径，不给结论。
